
# moonupp | Universal Banking for the Web3 Economy

This repository contains the high-fidelity presentation and webapp for moonupp, a US banking-as-a-service platform.

## 🛠 Manual Installation
1. Clone the repo.
2. Run `npm install`.
3. Run `npm run dev` to start the local development server.
4. Run `npm run build` to generate the production `dist` folder.

## 🏗 Project Architecture
- **React 19**: UI Framework.
- **Tailwind CSS**: Styling.
- **Vite**: Build pipeline.
- **Multi-language**: Built-in i18n support (EN/ZH).
